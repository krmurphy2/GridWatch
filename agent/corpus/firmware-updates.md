# Router firmware updates

Firmware is the software that runs your router. Like the operating system on a
phone, it gets security fixes over time. Running old firmware leaves known holes
open that attackers actively look for.

## Why updates matter

When a security flaw is found in a router, the manufacturer usually releases a
firmware update that fixes it. Until you install that update, your router stays
vulnerable to that specific, publicly documented problem — even if everything
appears to work fine.

## How to update

- Check the router's admin page for a "Firmware", "Router Update", or "Software
  Update" section. Many modern routers can check for and install updates
  automatically; turning on automatic updates is the easiest way to stay current.
- If there is no automatic option, look up your exact model and current firmware
  version on the manufacturer's support site and follow their update steps.
- Do not download firmware from unofficial or third-party sites.

## End-of-life routers

If the manufacturer no longer provides updates for your model (it has reached
"end of life"), it will not receive fixes for new vulnerabilities. For a router
that is several years past support, the safest long-term fix is to replace it with
a currently supported model.
